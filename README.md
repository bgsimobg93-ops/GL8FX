# GL8FX Training Hub

Ready-to-deploy Next.js project for GL8FX.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Upload this project to GitHub, then import it into Vercel or Netlify.

## Important

- Your logo file should be placed in `public/logo-gl8fx.png`
- Replace the sample video embed URLs in `app/page.tsx`
